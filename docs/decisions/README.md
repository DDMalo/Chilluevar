# Decision records

One file per architectural decision: the problem, what we chose, what we
rejected and why. They are numbered and not edited once taken; if a decision
changes, a new record supersedes the old one and the old one is marked as such.

This is not paperwork. It is what lets us explain, months later, why the project
is built this way instead of shrugging.
